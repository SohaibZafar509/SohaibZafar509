## 📌 Featured Work

### Project MUSA – Mining Unstructured Data using AI
Built a distributed Go-based microservices pipeline integrating PostgreSQL, MinIO (S3), and RabbitMQ for event-driven data ingestion 
and AI/RAG analytics use cases. 
Implemented secure APIs with presigned uploads and OIDC/Keycloak authentication; designed retry/DLQ mechanisms for system 
resilience. 
Deployed containerized services via Docker with GHCR image publishing and Nginx production routing; developed React frontend for 
operational insights. 

**Tech Stack:** React, Node.js, Express, MiniIO(S3), RabbitMQ, GoLang, Containers, Docker.
